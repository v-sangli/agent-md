> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add the `agent-docs` skill and the user-scoped store `~/.agent-docs/` it keeps, wire its index into every session, and remove `.claude/ENV.md`.

**Architecture:** A Bash script (`agent_docs.sh index|check`) is the store's only validator and generates `INDEX.md` from each doc's one-line frontmatter. `CLAUDE.md` imports the index; the session hook prints `check`. | Exit | Meaning | Output |
|---|---|---|
| 0 | store valid (`check`) / index written (`index`) | stdout: `agent-docs: OK (<n> docs)` |
| 1 | invalid store | stderr: `agent-docs: <rel-path or root>: <reason>`, first failure only |
| 2 | usage error | stderr: usage |

Reasons: `missing root`, `no frontmatter`, `unknown or extra frontmatter key`, `empty description`, `description not on one line`, `index missing`, `index stale`.

```text
list_docs ROOT            -> sorted rel paths, one per line
validate_doc ROOT REL     -> exit 1 + reason on stderr; called once per doc, the only validation
description_of ROOT REL   -> the description text (trusts validate_doc ran)
render_index ROOT         -> INDEX.md content on stdout (trusts validation)
cmd_index ROOT            -> validate all, then write render_index to INDEX.md
cmd_check ROOT            -> validate all, then diff render_index against INDEX.md
```


**Step 4: Write the script**

`.claude/skills/agent-docs/scripts/agent_docs.sh`:

```bash
#!/usr/bin/env bash
# Validate the agent-docs store and generate its INDEX.md.
# This script is the store's only validator: the functions after validate_all trust it.
set -euo pipefail
export LC_ALL=C

usage() {
  printf 'usage: agent_docs.sh [--root DIR] index|check\n' >&2
  exit 2
}

fail_store() { # WHERE REASON
  printf 'agent-docs: %s: %s\n' "$1" "$2" >&2
  exit 1
}

list_docs() { # ROOT -> sorted rel paths, one per line
  (cd "$1" && find . -path '*/.*' -prune -o -type f -name '*.md' ! -path ./INDEX.md -print) |
    sed 's|^\./||' | sort
}

description_of() { # ROOT REL -> the description text
  sed -n '2s/^description:[[:space:]]*//p' "$1/$2"
}

validate_doc() { # ROOT REL
  local file="$1/$2" line1 line2 line3
  line1="$(sed -n 1p "$file")"
  line2="$(sed -n 2p "$file")"
  line3="$(sed -n 3p "$file")"
  [ "$line1" = "---" ] || fail_store "$2" "no frontmatter"
  case "$line2" in
    description:*) ;;
    *) fail_store "$2" "unknown or extra frontmatter key" ;;
  esac
  [ -n "$(description_of "$1" "$2")" ] || fail_store "$2" "empty description"
  if [ "$line3" != "---" ]; then
    if [[ "$line3" =~ ^[A-Za-z_][A-Za-z0-9_-]*: ]]; then
      fail_store "$2" "unknown or extra frontmatter key"
    fi
    fail_store "$2" "description not on one line"
  fi
}

validate_all() { # ROOT -> the number of docs on stdout
  local rel n=0
  [ -d "$1" ] || fail_store "$1" "missing root"
  while IFS= read -r rel; do
    validate_doc "$1" "$rel"
    n=$((n + 1))
  done < <(list_docs "$1")
  printf '%d\n' "$n"
}

index_line() { # ROOT REL
  printf -- '- `%s`: %s\n' "$2" "$(description_of "$1" "$2")"
}

render_index() { # ROOT -> INDEX.md content on stdout
  local docs roots rel dir
  docs="$(list_docs "$1")"
  cat <<'EOF'
# Agent docs

Generated by `agent_docs.sh index` from each doc's frontmatter. Do not edit.
Paths are relative to the store root.
EOF
  roots="$(printf '%s\n' "$docs" | awk 'NF && !/\//')"
  if [ -n "$roots" ]; then
    printf '\n'
    while IFS= read -r rel; do
      index_line "$1" "$rel"
    done <<<"$roots"
  fi
  while IFS= read -r dir; do
    printf '\n## %s\n' "$dir"
    while IFS= read -r rel; do
      index_line "$1" "$rel"
    done < <(printf '%s\n' "$docs" | awk -v d="$dir" '{ p = $0; if (sub(/\/[^\/]*$/, "", p) && p == d) print }')
  done < <(printf '%s\n' "$docs" | awk '/\// { sub(/\/[^\/]*$/, ""); print }' | sort -u)
}

cmd_index() { # ROOT
  local n
  n="$(validate_all "$1")"
  render_index "$1" >"$1/INDEX.md"
  printf 'agent-docs: OK (%d docs)\n' "$n"
}

cmd_check() { # ROOT
  local n
  n="$(validate_all "$1")"
  [ -f "$1/INDEX.md" ] || fail_store "INDEX.md" "index missing"
  cmp -s <(render_index "$1") "$1/INDEX.md" || fail_store "INDEX.md" "index stale"
  printf 'agent-docs: OK (%d docs)\n' "$n"
}

root="$HOME/.agent-docs"
if [ "$#" -ge 2 ] && [ "$1" = "--root" ]; then
  root="$2"
  shift 2
fi
[ "$#" -eq 1 ] || usage
case "$1" in
  index) cmd_index "$root" ;;
  check) cmd_check "$root" ;;
  *) usage ;;
esac
```

**Step 3: Write `SKILL.md`**

````markdown
---
name: agent-docs
description: Use before working with a tool, host, environment or device of this workspace, and whenever you learn, or the user gives or corrects, a fact about one. Keeps the user-scoped store of workspace facts, ~/.agent-docs/, and its generated index.
---

# Agent Docs

The store of workspace facts: what it takes to work with the user's tools, hosts and
repos. There is one store per user, `~/.agent-docs/`, outside every repo. The user reads
it and adds to it; the agent keeps it current.

## The store

- A doc is any `*.md` under `~/.agent-docs/`, except `INDEX.md` and any path with a
  component starting with `.`. Subdirectories follow concerns, any depth. A doc's path
  is its identity.
- Its first three lines are exactly:

  ```text
  ---
  description: <what this doc covers, on one line, written for recall>
  ---
  ```

  The body is free markdown.
- `INDEX.md` is generated from the descriptions. It is never edited by hand.
- Facts, not rules. A line that tells the agent how to behave belongs in `CLAUDE.md`.
- Real credentials are recorded as pointers: where the secret lives and how to fetch it.
  Low-stakes values may be written inline.

## Look up

`CLAUDE.md` imports the index, so it is in context. Before working with a tool, host,
environment or device, read the doc the index names for it. If the session-start output
reports the store missing or broken, tell the user.

## Write

When you learn a workspace fact, or the user gives or corrects one:

1. Put it in the doc that covers its concern, or create a doc in the right directory,
   frontmatter first.
2. From the workspace root, run `bash .claude/skills/agent-docs/scripts/agent_docs.sh index`.
3. Tell the user in one line: the doc's path and what changed.

Write without asking. Rewriting or removing content already in a doc is proposed first,
with the change shown: it may be something the user wrote.

## Organize

- One concern per doc. A doc that has grown to cover two is split; two docs that overlap
  are merged. Both are rewrites, so both are proposed first.
- Directories follow concerns. A description is specific enough to choose the doc from
  the index alone.

## The script

`agent_docs.sh [--root DIR] index|check`, `--root` defaulting to `~/.agent-docs`.

- `index` validates every doc, then rewrites `INDEX.md`.
- `check` validates every doc and that `INDEX.md` is current.

Both print `agent-docs: OK (<n> docs)`, or exit 1 with `agent-docs: <path>: <reason>` for
the first invalid doc, and `index` then leaves `INDEX.md` unchanged. Fix the doc it names
and run it again.
````
